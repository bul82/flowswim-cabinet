# FlowSwim Telegram Mini App

Личный кабинет спортсмена для детских курсов по плаванию. Интерфейс рассчитан на запуск внутри Telegram через Mini App.

## Что есть в MVP

- 2 профиля: ученик/родитель и тренер;
- профиль ребенка;
- ближайшая тренировка;
- посещаемость, навык недели, статус оплаты;
- контакты родителей с телефонами и Telegram;
- прогресс по навыкам;
- тренерский список из 3 учеников;
- документы и статусы.

## Авторизация и роли

В Telegram Mini App авторизация идет через Telegram ID пользователя.

- В интерфейсе MVP оставляем 2 профиля: `Ученик` и `Тренер`.
- В модели доступа закладываем 4 роли: `child`, `parent`, `coach`, `admin`.
- Если Telegram ID найден в таблице родителей, открывается профиль `Ученик`.
- Родитель видит только своего ребенка или своих детей.
- Ребенок может подключиться со своего телефона и получает ограниченный доступ.
- Если Telegram ID найден в таблице тренеров, открывается профиль `Тренер`.
- Тренер видит учеников только из своих групп.
- Админ позже управляет группами, тренерами, доступами и расписанием.
- Если один человек одновременно родитель и тренер, показываем переключатель ролей.
- Если Telegram ID не найден, показываем экран запроса доступа.

В MVP роль можно переключить вручную, чтобы проверить оба сценария интерфейса.

Подробный план доступа: [ACCESS_MODEL.md](ACCESS_MODEL.md).

## Как подключить к Telegram

1. Создать бота в `@BotFather` через `/newbot`.
2. Получить HTTPS-адрес приложения после публикации.
3. В `@BotFather` открыть настройки бота и добавить Mini App URL.
4. При необходимости настроить кнопку меню бота на этот же URL.

Telegram Mini App должен открываться по HTTPS. Локальный файл или обычный `http://localhost` для реального запуска в Telegram не подойдет.
